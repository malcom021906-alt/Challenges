# Gestión de Contactos - Challenges Moviles

El repositorio esta destinado para subir los Challenges de la Asignatura de desarrollo para pltaformas moviles.
Los challenges se suben a la rama correspondiente es decir el challenge *1 esta en la rama Challenge1.

## Tecnologías Utilizadas

- **Ionic Framework**: Para componentes de UI móviles.
- **React**: Biblioteca principal de UI.
- **TypeScript**: Para tipado estático.
- **Vite**: Herramienta de construcción rápida.
- **Tailwind CSS**: Para estilos modernos y personalizados.

## Configuración y Ejecución

Este proyecto utiliza una configuración minimalista de React + TypeScript + Vite con reglas de ESLint.

### Comandos Disponibles

- `npm run dev`: Inicia el servidor de desarrollo.
- `npm run build`: Compila la aplicación para producción.
- `npm run lint`: Ejecuta el análisis de código.
- `npm run preview`: Previsualiza la versión compilada.
